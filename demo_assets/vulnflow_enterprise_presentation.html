🏛️ Technical Architecture

4-Tier Enterprise Architecture

Strict boundary isolation between generative intelligence, deterministic policy, and sandboxed execution.

TIER 1 • INGESTION
Scanner Adapters & Redaction

Parses SARIF & JSON from Trivy, Grype, Gitleaks, and Snyk. Immediately redacts all secrets and API tokens so plaintext never touches LLMs.

TIER 2 • ORCHESTRATION
LangGraph & Multi-Agent Swarm

Interruptible state machine coordinating specialized agents (Triage, Root-Cause, Planner, Fixer, Verifier) with state persistence and human review gates.

TIER 3 • TOOLS (FastMCP)
FastMCP Tool Servers

Side-effects strictly isolated via Model Context Protocol JSON-RPC stdio servers: Git, Build Sandbox, Policy, Scanner, and Jira ticketing.

TIER 4 • VERIFICATION
Sandbox & Knowledge RAG

Ephemeral container sandbox executes builds, runs unit tests, and triggers rescan diffs against Neo4j dependency graphs and advisory vector stores.
